# 🚗 Car Management Showroom System

A Java OOP-based console application that simulates a smart car showroom. It provides car inventory management, AI-powered recommendations, and voice assistant interaction.

## Features
- 🚘 Add and manage cars
- 🚙 Support for SUV, Sedan, and Hatchback
- 🤖 AI-powered car recommendation system
- 🎙️ Voice assistant interaction
- 🔍 Search and update car details
- 🧩 Demonstrates OOP concepts like Inheritance, Polymorphism, Abstraction, and Encapsulation

## Technologies Used
- Java
- IntelliJ IDEA
- Git & GitHub
